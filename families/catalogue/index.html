    Complete family catalogue¶

    Generated from the library (tools/catalogue.f90): every family code fortvine accepts, its name, number of parameters and parameter box. Exch. = exchangeable (C(u,v) = C(v,u)); asymmetric families are transposed exactly when a vine edge is flipped. Every family except the rotationless ones also has 90, 180 and 270 degree rotations.
